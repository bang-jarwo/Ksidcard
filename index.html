KONFIGURASI

Pengaturan aplikasi

Hubungkan Google Apps Script dan atur identitas serta desain kartu.

1. Koneksi database

Alamat URL dan kode akses disimpan di browser untuk sesi penggunaan. Data siswa tetap berada di Google Spreadsheet/Drive.

2. Identitas sekolah

3. Desain kartu

4. Aturan pemegang kartu

5. Data siswa

Data siswa dikelola di sheet DATA_SISWA pada Google Spreadsheet. Kolom minimal: NISN, NAMA, JENIS_KELAMIN, TTL, ALAMAT, KELAS, JURUSAN, FOTO_URL.

Foto dapat diunggah melalui lembar Google Drive dengan URL file yang dapat dibaca oleh pengguna aplikasi. Panduan impor tersedia di README.

MULAI PENGGUNAAN

Panduan pemasangan

  1. Unggah folder frontend ke repository GitHub dan aktifkan GitHub Pages.
  2. Buat project Google Apps Script baru, tempel file backend/Code.gs, lalu jalankan fungsi setup().
  3. Deploy sebagai Web App: Execute as Me, akses Anyone. Salin URL /exec.
  4. Buka aplikasi GitHub Pages, masuk Pengaturan, masukkan URL /exec dan kode admin.
  5. Isi DATA_SISWA di spreadsheet. Klik Sinkronkan untuk memuat data.

Catatan: aplikasi ini menggunakan Google Apps Script sebagai backend. Kode admin awal harus segera diganti di Script Properties setelah setup. Batasi akses URL spreadsheet dan folder Drive sesuai kebijakan sekolah.
